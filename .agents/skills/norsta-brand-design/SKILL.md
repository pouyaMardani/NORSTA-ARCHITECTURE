# Norsta Brand Design

## Project Identity

- Norsta is a portfolio and educational website focused on microcement and artistic patina finishes.
- The primary purpose is to showcase real completed work and help visitors understand these finishes.
- The website must present the work professionally and build trust through accurate information and authentic imagery.
- Treat Norsta as a distinctive brand, not a generic construction company template.
- Use the verified project brief and owner-approved assets as the source of truth.
- Do not invent brand history, certifications, awards, client relationships, or business claims.

## Inspect Before Designing

- Read the project roadmap, existing pages, global styles, and design tokens before making changes.
- Review available logos, brand assets, and approved photography.
- Preserve existing design decisions unless the project owner requests a change or a clear problem needs to be fixed.
- Avoid replacing the overall visual direction during unrelated implementation tasks.
- If a major brand decision is missing, propose a clear recommendation rather than silently inventing a permanent rule.

## Visual Direction

- Aim for a premium, artistic, architectural, and material-focused visual identity.
- Let authentic microcement and patina photography contribute strongly to the visual character.
- Use typography, whitespace, alignment, and restrained visual details to communicate quality.
- Keep the interface elegant and readable rather than overloaded with decoration.
- Avoid generic template layouts that make the site look indistinguishable from unrelated businesses.
- Avoid excessive gradients, glass effects, animations, shadows, and decorative elements.
- Do not sacrifice loading speed or accessibility for visual effects.

## Design Consistency

- Reuse shared components, design tokens, and established layout patterns.
- Keep buttons, cards, navigation, section spacing, and typography consistent.
- Use a limited and purposeful set of colors and component variants.
- Avoid introducing a new visual language for each page.
- Keep the homepage, article listing, article details, and portfolio sections recognizably part of one brand.

## Themes

- Implement light and dark themes only if they remain part of the approved project requirements.
- Maintain readable contrast and consistent brand expression in both themes.
- Ensure theme switching works without broken styling or inaccessible controls.
- Avoid duplicating entire components just to support different themes.
- Respect the existing theme architecture.

## Photography and Authenticity

- Use approved, authentic project photographs whenever available.
- Do not present generated images, stock photography, or visual placeholders as real Norsta projects.
- If a temporary placeholder is required during development, make its temporary status clear.
- Do not alter photographs in ways that misrepresent the actual finish or completed work.
- Use image crops that preserve important material details.

## Responsive Design

- Preserve the brand's visual hierarchy on mobile, tablet, and desktop.
- Do not simply shrink the desktop layout to fit mobile screens.
- Adapt galleries, typography, navigation, and spacing to the available viewport.
- Avoid horizontal overflow, clipped headings, and crowded controls.

## Implementation Rules

- Follow the project's installed Next.js, React, TypeScript, and Tailwind CSS versions.
- Inspect existing dependencies before adding a design library.
- Prefer reusable components and maintainable styling.
- Keep brand tokens centralized where practical.
- Do not rewrite unrelated components during a visual update.

## Verification

- Inspect the rendered page rather than relying only on source code.
- Compare related pages for visual consistency.
- Test responsive layouts and theme behavior where applicable.
- Check typography, contrast, image crops, and interaction states.
- Run relevant project checks after implementation.

## Completion Standard

Every page should feel like part of the same distinctive Norsta brand. Visual quality, authentic presentation, accessibility, maintainability, and performance must remain balanced.
